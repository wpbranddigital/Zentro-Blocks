== Description ==

**Zentro Blocks is a free WordPress plugin that adds a design library of 74 block patterns and 18 full page templates, plus 17 interactive Gutenberg blocks, to the WordPress block editor.** Click "Zentro Patterns" in the editor toolbar, pick a design and insert it in one click. Every section is fully editable, responsive and built with native blocks – no page builder, no shortcodes, no lock-in.

Use it to build a business website, agency site, landing page, SaaS homepage, portfolio, real estate site, clinic website or charity site in minutes instead of days.

= What is Zentro Blocks? =

Zentro Blocks is a Gutenberg block library and pattern library in one plugin:

* **Design library** – 74 ready-made section patterns and 18 full page templates with real demo content and images.
* **17 Gutenberg blocks** – tabs, accordion, pricing table, animated counter, container, gallery, team, testimonials, timeline and more.
* **Native block editor** – everything is built from WordPress blocks, so it works with block themes such as Twenty Twenty-Five and keeps working if you switch themes.

= How does it work? =

1. Open any page or post in the block editor.
2. Click **Zentro Patterns** in the top toolbar.
3. Choose a **pattern** (one section) or a **page template** (a complete page) and click **Insert**.
4. Replace the demo text and images with your own and publish.

Inserted designs are regular blocks. There is nothing proprietary to learn and nothing to break when you update.

= Fast by design =

* The design library is loaded only when you open it. The editor script stays around 18 KB.
* The library shows 6 patterns or 4 templates at a time and loads more as you scroll.
* On the front end, demo images are lazy-loaded and the first image gets high fetch priority to help Largest Contentful Paint (LCP).
* No jQuery and no page builder runtime on the front end.

= Responsive and accessible =

* Every pattern and template is tested at desktop (1366 px), tablet (820 px) and mobile (390 px) widths.
* Tabs and accordions use ARIA roles and support keyboard navigation.
* Clean, semantic HTML output from native WordPress blocks.

= External services =

Zentro Blocks works without any account or API key. Two optional features load files from third-party services:

* **Demo images (Unsplash).** The demo images inside patterns and page templates are loaded from images.unsplash.com when a page using them is viewed. Your visitor's browser requests the image from Unsplash, which receives the visitor's IP address and browser details. Replace the demo images with images from your Media Library to stop these requests. Unsplash [terms](https://unsplash.com/terms) and [privacy policy](https://unsplash.com/privacy).
* **Google Fonts (optional).** If you choose a Google Font under *Zentro Blocks > Global Settings*, the font stylesheet is loaded from fonts.googleapis.com on your site and in the editor. No font is loaded while the setting is "Inherit" (the default). Google Fonts [terms](https://developers.google.com/fonts/terms) and [privacy policy](https://policies.google.com/privacy).
* **Advanced Map block.** Only on pages that contain a map. With the OpenStreetMap provider, the Leaflet map library is loaded from unpkg.com and map tiles from tile.openstreetmap.org, tile.openstreetmap.de or basemaps.cartocdn.com (CARTO), depending on the map style you choose. With the Google Maps provider, the Google Maps JavaScript API is loaded from maps.googleapis.com using your own API key. These services receive the visitor's IP address and browser details. unpkg [website](https://unpkg.com/), OpenStreetMap [privacy policy](https://osmfoundation.org/wiki/Privacy_Policy), CARTO [privacy policy](https://carto.com/privacy), Google Maps [terms](https://cloud.google.com/maps-platform/terms) and [privacy policy](https://policies.google.com/privacy).

Zentro Blocks does not collect, store or send any personal data or usage statistics.

== Installation ==

= From your WordPress dashboard =

1. Go to **Plugins > Add New Plugin**.
2. Search for **Zentro Blocks**.
3. Click **Install Now**, then **Activate**.
4. Open any page in the block editor and click **Zentro Patterns** in the toolbar.

= Manual installation =

1. Download the plugin ZIP file.
2. Go to **Plugins > Add New Plugin > Upload Plugin**.
3. Upload the ZIP file, click **Install Now**, then **Activate**.

After activation, visit **Zentro Blocks > My Suite** to turn individual blocks on or off, and **Zentro Blocks > Global Settings** to set your brand colour and font.

== Frequently Asked Questions ==

= What is Zentro Blocks? =

Zentro Blocks is a free WordPress plugin that adds 74 block patterns, 18 page templates and 17 interactive blocks to the Gutenberg block editor. It helps you build complete, responsive websites using only native WordPress blocks.

= Is Zentro Blocks free? =

Yes. All patterns, page templates and blocks described on this page are free and fully functional. There are no locked features and no account is required.

= How do I insert a pattern or page template? =

Open a page in the block editor, click **Zentro Patterns** in the top toolbar, choose the **Patterns** or **Page Templates** tab, then click **Insert** on any design. If a block is selected, the design is inserted below it; on an empty page it fills the page.

= Do I need a page builder like Elementor? =

No. Zentro Blocks works inside the default WordPress block editor (Gutenberg). Every design is made of native blocks, so you don't need a separate page builder.

= Which themes does it work with? =

It is designed for block themes such as Twenty Twenty-Five and works with any theme that supports the block editor. For full-width sections we recommend a page template without a title, such as "Page No Title" in Twenty Twenty-Five.

= Are the patterns and templates responsive? =

Yes. Every design is tested on desktop, tablet and mobile screen sizes, and the Container block has separate column, spacing and gap settings for each device.

= Will Zentro Blocks slow down my website? =

No. The design library only loads inside the editor when you open it, and it adds no page builder scripts to your front end. Demo images are lazy-loaded, and you can replace them with optimised images from your Media Library.

= Can I use Zentro Blocks for a real estate website? =

Yes. There is a Real Estate pattern pack (property hero, listings, featured properties, property search, agent profiles, property details and gallery), an architecture and real estate page template, and real estate examples in the Services, Case Study and Portfolio pages.

= Can I put other blocks inside the Tabs block? =

Yes. Each tab is a container for any block – paragraphs, images, buttons, columns, pricing cards or even another Tabs block. Tabs created with older versions are converted automatically.

= Can I change the colours and fonts of the designs? =

Yes. Every inserted design is made of normal blocks, so you can change colours, fonts, spacing and images in the block settings sidebar. You can also set a global brand colour and Google Font under Zentro Blocks > Global Settings.

= Can I use the demo images on my live site? =

The demo images are meant as placeholders that show how a design looks. We recommend replacing them with your own photos from the Media Library before you publish.

= How do I turn off blocks I don't use? =

Go to **Zentro Blocks > My Suite** in your dashboard and switch off any block you don't need. Disabled blocks are not registered in the editor.
