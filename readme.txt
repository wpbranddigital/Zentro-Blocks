== Description ==

**Zentro Blocks is a lightweight pattern library for the WordPress block editor.** It gives you ready-made sections and complete pages – about, team, services, pricing, case study, portfolio and more – designed for agencies, real estate businesses, clinics, coaches and small companies. Click **Zentro Patterns** in the editor toolbar, choose a design and insert it. Then change the text and images and publish.

It is not a page builder and it does not replace your theme. Everything you insert is made of normal WordPress blocks, so your pages stay fast, editable and portable – even if you switch themes or uninstall the plugin later.

= Who is it for? =

* **Small business owners** who want a professional website without learning a page builder.
* **Freelancers and small agencies** who build client sites and want good-looking sections they can reuse.
* **Real estate agents and property developers** who need listing, agent and property pages.
* **Clinics, dentists and healthcare practices** who need service, doctor and appointment sections.
* **Coaches, consultants, non-profits and startups** who need a clean landing page and the usual inner pages.

= Why Zentro Blocks? =

Many block plugins try to do everything. Zentro Blocks focuses on one job: **helping you finish real pages quickly with designs that already look right.**

* **Real content, not lorem ipsum** – every design comes with realistic demo text and images, so you can see how the finished page will look.
* **Inner pages included** – most libraries focus on homepages. Zentro Blocks also gives you the pages every business website needs: about, team, services, service details, pricing, case study and portfolio.
* **Industry packs** – sections made for digital agencies, healthcare and clinics, and real estate.
* **Native blocks only** – no shortcodes, no proprietary layout engine, no lock-in.
* **No account, no sign-up, no locked designs** – everything in the library is free to use.
* **Light on your site** – the design library loads only when you open it in the editor, and nothing extra runs on your front end.

= How does it work? =

1. Open any page or post in the block editor.
2. Click **Zentro Patterns** in the top toolbar.
3. Choose a **pattern** (a single section) or a **page template** (a complete page).
4. Click **Insert**, replace the demo text and images, and publish.

If a block is selected, the design is added right below it. On an empty page it fills the page.

= Interactive blocks =

The patterns are built with core blocks plus a small set of Zentro blocks you can also use on their own:

* **Container / Section** – flex and grid layouts with separate settings for desktop, tablet and mobile.
* **Tabs** – put *any* block inside each tab: images, buttons, columns, pricing cards or even another tab set. Keyboard and screen-reader friendly.
* **Accordion / FAQ**, **Pricing Table**, **Animated Counter**, **Image Gallery**, **Team Member**, **Testimonials Carousel**, **Feature Card**, **CTA Banner**, **Popup / Modal**, **Progress Tracker**, **Timeline & Roadmap**, **Before / After Image Comparison**, **Image Hotspot**, **Map** and **Interactive Button**.

Don't need some of them? Switch them off under **Zentro Blocks > My Suite** and they won't appear in the editor.

= Fast, responsive and accessible =

* Every design is checked on desktop, tablet and mobile screen sizes.
* The design library is loaded only when you open it, so the editor stays quick.
* Demo images are lazy-loaded, and the first image is prioritised to help page speed.

= Works with your setup =

Zentro Blocks is designed for block themes such as Twenty Twenty-Five and works with any theme that supports the block editor. Because it only adds patterns and a few focused blocks, it can be used alongside your favourite theme and other block plugins.

= External services =

Zentro Blocks works without any account or API key. Some optional features load files from third-party services:

* **Demo images (Unsplash).** The demo images inside patterns and page templates are loaded from images.unsplash.com when a page using them is viewed. Your visitor's browser requests the image from Unsplash, which receives the visitor's IP address and browser details. Replace the demo images with images from your Media Library to stop these requests. Unsplash [terms](https://unsplash.com/terms) and [privacy policy](https://unsplash.com/privacy).
* **Google Fonts (optional).** If you choose a Google Font under *Zentro Blocks > Global Settings*, the font stylesheet is loaded from fonts.googleapis.com on your site and in the editor. No font is loaded while the setting is "Inherit" (the default). Google Fonts [terms](https://developers.google.com/fonts/terms) and [privacy policy](https://policies.google.com/privacy).
* **Map block.** Only on pages that contain a map. With the OpenStreetMap provider, the Leaflet map library is loaded from unpkg.com and map tiles from tile.openstreetmap.org, tile.openstreetmap.de or basemaps.cartocdn.com (CARTO), depending on the map style you choose. With the Google Maps provider, the Google Maps JavaScript API is loaded from maps.googleapis.com using your own API key. These services receive the visitor's IP address and browser details. unpkg [website](https://unpkg.com/), OpenStreetMap [privacy policy](https://osmfoundation.org/wiki/Privacy_Policy), CARTO [privacy policy](https://carto.com/privacy), Google Maps [terms](https://cloud.google.com/maps-platform/terms) and [privacy policy](https://policies.google.com/privacy).

Zentro Blocks does not collect, store or send any personal data or usage statistics.

== Installation ==

= From your WordPress dashboard =

1. Go to **Plugins > Add New Plugin**.
2. Search for **Zentro Blocks**.
3. Click **Install Now**, then **Activate**.
4. Open any page in the block editor and click **Zentro Patterns** in the toolbar.

= Manual installation =

1. Download the plugin ZIP file.
2. Go to **Plugins > Add New Plugin > Upload Plugin**.
3. Upload the ZIP file, click **Install Now**, then **Activate**.

After activation, visit **Zentro Blocks > My Suite** to turn individual blocks on or off, and **Zentro Blocks > Global Settings** to set your brand colour and font.

== Frequently Asked Questions ==

= What is Zentro Blocks? =

Zentro Blocks is a free WordPress plugin that adds a library of ready-made block patterns and page templates to the block editor, plus a few interactive blocks such as tabs, accordion and pricing tables. It helps you build complete business websites using only native WordPress blocks.

= Is Zentro Blocks a page builder? =

No. Zentro Blocks works inside the default WordPress block editor. It adds designs made of normal blocks, so you don't need to learn a separate builder and your content is never locked in.

= Is it free? =

Yes. Every pattern, page template and block in the plugin is free to use. There are no locked designs and no account is required.

= How do I insert a pattern or page template? =

Open a page in the block editor, click **Zentro Patterns** in the top toolbar, choose the **Patterns** or **Page Templates** tab and click **Insert** on any design.

= Which pages can I build with it? =

Home pages and landing pages, plus the inner pages most business sites need: about, team, services, service details, pricing, case study, portfolio, FAQ and contact sections.

= Can I use it for a real estate website? =

Yes. There is a real estate pattern pack with property hero, listings, featured properties, property search, agent profiles, property details and gallery sections, plus an architecture and real estate page template.

= Can I use it for a clinic or dental website? =

Yes. The healthcare pack includes medical hero, doctor profiles, medical services, appointment, opening hours, patient reviews and FAQ sections, and there is a complete dental clinic template.

= Will it work with my theme? =

It is designed for block themes such as Twenty Twenty-Five and works with any theme that supports the block editor. For full-width sections we recommend a page template without a title, such as "Page No Title" in Twenty Twenty-Five.

= Can I use it together with other block plugins? =

Yes. Zentro Blocks only adds patterns and a focused set of blocks, so it can run alongside other block plugins. You can also switch off any Zentro block you don't need.

= Are the designs responsive? =

Yes. Every design is checked on desktop, tablet and mobile, and the Container block has separate column, spacing and gap settings for each device.

= Will it slow down my website? =

No. The design library only loads inside the editor when you open it, and the plugin adds no page builder scripts to your front end. Demo images are lazy-loaded, and you can replace them with optimised images from your Media Library.

= Can I put other blocks inside the Tabs block? =

Yes. Each tab can hold any block – paragraphs, images, buttons, columns, pricing cards or even another Tabs block. Tabs made with older versions are converted automatically.

= Can I change colours and fonts? =

Yes. Inserted designs are normal blocks, so you can change colours, fonts, spacing and images in the block settings. You can also set a global brand colour and font under Zentro Blocks > Global Settings.

= Should I keep the demo images? =

The demo images are placeholders that show how a design looks. Replace them with your own photos from the Media Library before you publish.
